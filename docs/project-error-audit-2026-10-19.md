# Проверка ошибок проекта — 19.10.2026

Исходная точка: `main` `e543351` (PR #188), версия 3.85.0. Работа ограничена `deputat36/etagi`. Целевая 3.86.0 остаётся DRAFT.

## Импорт, экспорт и сохранения

Исправлен первый блок подтверждённых ошибок:

- Собственный JSON после автоматической компоновки отклонялся: `layoutMode=auto` отсутствовал в допустимых значениях. Также отклонялись универсальные заготовки с `goal=all`. Validator и опубликованная JSON Schema теперь принимают оба реально экспортируемых значения.
- Корректный JSON неправильной формы в `localStorage` (например, `null` вместо списка макетов или число вместо избранного) вызывал исключение при запуске. Чтение проверяет форму записей, сохраняет доступ к корректным макетам среди повреждённых; неверные типы известных полей состояния изолированы. Новое сохранение не стирает корректные старые записи.
- Адрес фото вставлялся в HTML без экранирования. Кавычки из импортируемого файла могли добавлять атрибуты к изображению. Оба `src` экранируются общим `esc`; допустимый адрес сохраняется при чтении DOM-атрибута.
- Во время загрузки библиотеки боковая форма уже принимала ввод, который поздняя инициализация могла заменить исходным шаблоном. До окончания загрузки форма помечена `aria-busy` и защищена `inert`, затем доступна для обычной работы; harness ждёт фактической готовности библиотеки.

Проверки блока: roundtrip экспорта/импорта всех 117 исходных шаблонов и 11 режимов компоновки, повреждённые списки и смешанные записи в storage, регрессия HTML-атрибутов в существующем браузерном harness, общий validate и browser/UI smoke. Числа и фактический результат CI фиксируются в соответствующем PR.

## Продолжение проверки

Следующие подтверждённые расхождения находятся в работе и этим блоком не исправлены:

1. Три слоя проверки новичка не включают утверждённый формат 3 на A4 в список готовых форматов.
2. Фото/QR: при загруженном только втором фото подсказка может вести снова к Фото 2; готовность требует проверки каждого исходного поля, а не одного количества тегов `img`.
3. Неподтверждённый покупатель в пяти рекомендованных новичку шаблонах, классификация `entrance_buyer_specific_house` и переполнения заполненных заготовок — из [аудита библиотеки](template-diversity-audit-2026-10-16.md).

Расширенная цифровая матрица проверяет 117 записей в исходном формате и дополнительно в офисном 2 на A4 (160 состояний) с тестовым профилем и явно тестовыми фото. Наблюдения renderer перепроверять в обычном интерфейсе; это не физическая печать. После исправлений проверить выбор, обязательные поля, inline-правку, сохранение/открытие и печать трёх основных задач на ПК и 360/390/430 px.

# UX слой целей СПН для выбора шаблонов

## Цель

Сделать выбор шаблона понятным для СПН без необходимости изучать названия и технические параметры.

## Принцип

СПН сначала выбирает рабочую задачу, а не макет.

Путь:

`Задача → Рекомендации → Шаблон → Адаптация → Проверка → Печать`

## Базовые цели

### Найти продавца

Для задач:
- поиск собственников квартир;
- поиск домов и участков;
- оценка недвижимости;
- формирование спроса в районе.

### Найти покупателя

Для задач:
- продвижение объекта;
- подбор вариантов;
- привлечение покупателей.

### Продвинуть объект

Для задач:
- квартира;
- дом;
- новостройка;
- специальное предложение.

### Рассказать о себе

Для задач:
- знакомство района;
- личный бренд СПН;
- доверие.

## Правила рекомендаций

Карточка шаблона должна отвечать:

1. Кому подходит?
2. Какую задачу решает?
3. Где использовать?
4. Что нужно заполнить?
5. Почему выбран этот вариант?

## Ограничения

- существующие templateId сохраняются;
- печатные пресеты не меняются;
- текущие проверки качества сохраняются;
- новый слой работает поверх существующих данных шаблонов.

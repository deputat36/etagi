# Реализация выбора шаблонов СПН

## Цель

Сделать первый экран генератора понятным для специалиста по недвижимости: сначала задача, затем подходящие шаблоны.

## Первый пользовательский сценарий

```
Задача СПН
↓
Рекомендованные шаблоны
↓
Карточка шаблона
↓
Адаптация
↓
Проверка
↓
Печать
```

## Принципы реализации

- не менять существующие templateId;
- не менять структуру печатных пресетов;
- не переносить логику шаблонов в интерфейс;
- использовать существующие данные шаблонов и слой целей СПН.

## Первый UI-этап

Экран выбора должен содержать:

1. Блок выбора задачи:
   - найти продавца;
   - найти покупателя;
   - продвинуть объект;
   - рассказать о себе.

2. Блок рекомендаций:
   - название шаблона;
   - кому подходит;
   - где использовать;
   - кнопка использования.

3. Быстрый переход в текущий редактор.

## Критерий готовности

Новый СПН должен понимать путь без объяснения менеджера и выбрать подходящий шаблон за несколько действий.

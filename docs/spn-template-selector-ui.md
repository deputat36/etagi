# Новый сценарий выбора шаблона СПН

## Цель

Сделать первый экран генератора понятным для специалиста по недвижимости: сначала выбрать задачу, затем получить подходящие шаблоны.

## Новый путь пользователя

```
Задача СПН
↓
Рекомендуемые варианты
↓
Карточка шаблона
↓
Адаптация данных
↓
Проверка
↓
Печать
```

## Первый экран

Заголовок:

«Что хотите сделать?»

Варианты:

### Найти продавца

Помогает получить обращения от собственников недвижимости.

Показываем:
- покупка квартиры;
- оценка недвижимости;
- спрос в районе.

### Найти покупателя

Помогает привлечь клиентов, которые хотят купить жильё.

Показываем:
- подбор квартир;
- объекты;
- консультацию.

### Продвинуть объект

Для конкретной квартиры, дома или новостройки.

### Рассказать о себе

Для развития личного бренда СПН.

## Карточка рекомендации

Карточка должна содержать:

- изображение макета;
- название без технических терминов;
- кому подходит;
- где использовать;
- что нужно заполнить;
- кнопку «Использовать шаблон».

## Принцип сортировки

Первым показывается не самый новый шаблон, а наиболее подходящий:

1. соответствие цели;
2. простота использования;
3. безопасность для новичка;
4. опыт предыдущего применения.

## Ограничения

- не менять существующие templateId;
- не менять печатный движок;
- не менять проверки качества;
- использовать существующие данные шаблонов.

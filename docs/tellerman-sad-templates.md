# Шаблоны ЖК «Теллерманов сад»

Пакет `data/templates_tellerman_sad.json` подключён через `assets/js/templates.js`. Сохранены все пять ID: универсальный подбор, семья, студия, ипотечная консультация, продажа своего жилья и покупка нового.

## Актуализация 19.10.2026

Прежние формулировки «продажи ещё не начались», «цены после старта» и «ранний список» устарели. На [странице проекта застройщика](https://bm36.ru/projects/tellermanov-sad/) указан старт продаж; [сайт проекта](https://tellermanovsad.ru/) содержит выбор квартир и цены. Это источники проверки этапа проекта, а не обещание сохранения цены или наличия конкретной квартиры.

Шаблоны теперь предлагают уточнить актуальные варианты, планировки и условия через личный контакт СПН. Не переносим в заготовки цены, акции, лимиты ипотеки или наличие квартир. Телефон застройщика не назначается всем пользователям.

Старые числа «70 квартир», «27,71 м²» и диапазоны площадей исключены из универсальных полей: сведения о конкретном доме, квартире и всём комплексе нельзя смешивать. Количество домов и состав очередей требуют сверки по конкретной проектной декларации. Фиксированную площадь и срок сдачи СПН вводит только для проверенного предложения.

## Пять сценариев

| ID | Задача | Контроль |
|---|---|---|
| `bgo_newbuild_tellerman_waitlist` | Подобрать квартиру и планировку | Прежний ID сохранён для совместимости; ранний список заменён актуальным подбором. |
| `bgo_newbuild_tellerman_family` | Обсудить жильё для семьи | Без утверждения, что семья подходит под ипотечную программу. |
| `bgo_newbuild_tellerman_studio` | Выбрать студию для первого жилья | Без фиксированной площади, доходности и обещания наличия. |
| `bgo_newbuild_tellerman_mortgage` | Предварительно обсудить бюджет и кредит | `test / manager / high / recommended=false`, полное предупреждение и проверка юристом. |
| `bgo_newbuild_tellerman_tradein` | Спланировать продажу и покупку | Менеджер проверяет конкретные объекты, сроки и договоры; одновременная сделка не обещается. |

Ипотечный макет этого пакета не входит в ранее реализованную матрицу 12 решений #51. Его собственное юридическое подтверждение остаётся обязательным; сохранение предупреждения не является заключением юриста. #126 и DRAFT 3.86.0 не закрываются.

## Что проверять перед печатью

1. Доступность квартиры, корпус, адрес, площадь и условия — по актуальному предложению и документам.
2. Цена и порядок услуг офиса — по конкретному договору; бесплатность и бронь без подтверждения не обещать.
3. Ипотеку, сертификаты и предупреждение — с профильным специалистом и юристом; ставки, платёж и одобрение не гарантировать.
4. Сохранить имя и телефон текущего СПН, проверить заполненный макет в основном формате 2 на A4 и нужном дополнительном формате.

Проверки: `npm run validate:templates`, `npm run validate:template-office-overrides`, `npm run validate:template-portfolio`, затем общий `npm run validate`. Поиск индексирует название, заметки, теги, печатный текст и расширенные поля контактов.

Validator сохраняет состав пакета, goal и ID, контролирует офисные уровни и запрещённые обещания, а также не допускает возврата устаревших формулировок этапа продаж. Он не является проверкой актуального наличия квартир.

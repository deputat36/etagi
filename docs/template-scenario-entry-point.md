# Точка входа по сценарию для СПН

Цель: заменить поиск шаблона с выбора дизайна на выбор рабочей задачи.

Путь пользователя:

1. СПН выбирает цель:
   - найти собственника;
   - найти покупателя;
   - продать объект;
   - продвинуть новостройку.

2. Система показывает подходящие шаблоны.

3. СПН выбирает макет и адаптирует данные.

Принципы:

- не менять существующие шаблоны;
- не менять печатный движок;
- сохранять быстрый доступ опытных пользователей;
- сначала показывать безопасные варианты для новичков.

# Сценарный выбор шаблонов

## Цель

СПН должен выбирать не макет, а задачу. Генератор сначала определяет сценарий работы, затем предлагает подходящие шаблоны.

## Новый путь

```
Задача СПН
↓
Сценарий
↓
Рекомендованные шаблоны
↓
Редактирование
↓
Проверка
↓
Печать
```

## Принцип

Существующий каталог шаблонов сохраняется. Сценарии являются дополнительным уровнем навигации и не меняют формат хранения готовых макетов.

## MVP-сценарии

- Продать объект
- Найти собственника
- Продвинуть новостройку
- Получить заявки по ипотеке

Следующий этап: подключить `template_scenarios.json` к интерфейсу выбора до открытия каталога шаблонов.
